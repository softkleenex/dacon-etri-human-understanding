# Gemini CLI (AI Agent) 자율 진화(Self-Evolving) 가이드

Gemini CLI는 단순한 코드 작성 도구를 넘어, 전체 프로젝트의 흐름을 관장하고 코드를 자율적으로 발전시키는 **메인 컨트롤 타워**입니다. 이 저장소 환경과 완벽하게 결합하여 휴먼-인-더-루프(HITL) 체제로 대회를 풀어나갑니다.

## 1. 역할 분담
사용자(당신)는 "방향성"을 제시하고, 에이전트(Gemini CLI)는 "실행 및 검증"을 담당합니다.
- **사용자 명령어 예시**: "현재 OOF 점수가 정체되었어. 날씨 데이터를 활용하는 피처 엔지니어링 코드를 `src/features.py`에 추가하고 `make test`로 검증해줘."
- **에이전트 행동**: 지시를 받아 파일을 읽고(`read_file`), 문맥을 파악한 뒤 부분적으로 코드를 수정(`replace`)하며 터미널 명령어를 실행(`run_shell_command`)해 결과를 도출합니다.

## 2. 자율 루프 모드 (`/ralph:loop`)
Dacon 제출이나 모델 튜닝 등, 반복적이고 인내가 필요한 작업을 자동화합니다.
```bash
/ralph:loop src/features.py에 이동 평균 피처 10개를 추가하고 모델을 학습시켜 점수를 확인해. 이전보다 점수가 오르면 제출을 준비하고, 떨어지면 수정한 피처를 롤백한 뒤 다시 다른 접근법으로 시도해. 총 5회 반복해줘.
```
위 명령어를 주면 알아서 에러를 고쳐가며 실험을 오케스트레이션합니다.

## 3. MCP 서브 에이전트 활용 전략
에이전트의 컨텍스트 길이를 아끼고 연산 속도를 높이기 위해, 복잡한 태스크는 특화된 에이전트에게 위임합니다.
- **코드베이스가 복잡해졌을 때**: `codebase_investigator` 서브 에이전트를 호출하여 "전체 데이터 파이프라인의 병목 구간을 찾아줘"라고 지시합니다.
- **대규모 단순 반복 변경**: "모든 스크립트 파일에 로거 포맷을 적용해줘"와 같은 일은 `generalist` 에이전트에게 백그라운드로 맡깁니다.

## 4. 제약 사항 및 안전
- 에이전트는 절대 `data/` 원본을 파괴하거나 민감한 키 값을 출력/커밋하지 않도록 시스템 프롬프트 레벨에서 통제됩니다.
- 코드 수정 전에는 반드시 어떤 이유로 무엇을 수정할 것인지 짧은 설명을 남깁니다.
