# Gemini CLI (AI Agent) 운영 매뉴얼

개발자가 일일이 코딩하는 대신 목표만 지시하고, 코드를 자율적으로 진화시키는 "휴먼-인-더-루프(HITL)" 체제를 위해 도입한 메인 컨트롤 타워(AI Agent)입니다.

## 🎯 사용 목적 (Why use this?)
- **사고의 추상화**: "어떻게 코딩할지" 고민하는 대신 "어떤 가설을 검증할지" 전략 수립에만 집중합니다. 논문 아이디어를 제시하면 코드 구현과 디버깅은 에이전트가 수행합니다.
- **무한 실험 반복 자동화**: 점수가 오를 때까지 파라미터를 깎고 피처를 교체하는 지루한 노가다를 에이전트의 자율 루프에 위임합니다.

## 🚀 사용 방법 (How to use?)

### 1. 인증 및 환경 변수 설정
Gemini CLI 자체의 구동을 위한 토큰은 툴 설치 시 기본 세팅되며, 에이전트가 W&B나 Hugging Face를 조작할 때는 시스템 전역(`~/.zshrc`)에 설정된 토큰을 스스로 읽어옵니다.

### 2. 자율 루프 (Ralph Loop) 스니펫
명령어 앞에 `/ralph:loop`를 붙이면, 목표를 달성할 때까지 에이전트가 스스로 에러를 디버깅하며 전진합니다.

```text
/ralph:loop "현재 로컬 K-Fold OOF 점수가 0.82에서 정체되었어. 
src/features.py에 날씨 데이터를 결합한 롤링 윈도우 피처를 5개 추가하고 `make test`로 검증해줘. 
통과하면 모델을 학습시키고, 점수가 0.83을 넘으면 멈추고 결과를 보고해. 에러가 나면 스스로 로그를 보고 수정해."
```

### 3. 서브 에이전트 위임 스니펫
컨텍스트(Token) 낭비를 막기 위해 무거운 작업은 전용 서브 에이전트를 호출하여 처리합니다.
```text
# 복잡한 버그 추적 시
"codebase_investigator를 호출해서 이 버그가 아키텍처 관점에서 왜 났는지 찾아줘."

# 대용량 텍스트 분석 시
"generalist를 호출해서 방금 돌아간 훈련 로그 5,000줄 중 오버피팅 발생 지점만 요약해줘."
```

## ⚠️ 실전 주의 사항
- **시스템 프롬프트 제약**: 에이전트는 폭주를 막기 위해 "원본 데이터(`data/raw`) 파괴 금지", "시크릿 토큰 평문 출력 금지" 규칙을 따릅니다.
- **Explain Before Acting**: 무작정 코드를 지우기 전에 에이전트는 항상 "왜 수정하는지" 사용자에게 1문장으로 보고하도록 통제됩니다. 파일 전체 덮어쓰기 대신 외과수술적인 부분 수정(`replace` 도구)을 유도하세요.
