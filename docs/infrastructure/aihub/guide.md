# AI Hub CLI (`aihubshell`) 가이드

오픈 데이터를 보조 데이터로 활용하여 모델의 강건성을 높이기 위한 파이프라인입니다.

## 상태: [적용 완료]

## 활용 목적
- 기상, 환경, 지리 공간 정보 등 모기 활동에 영향을 미칠 수 있는 외부 보조 데이터를 자동으로 확보.
- CLI 환경에서 스크립트를 통해 데이터를 직접 다운로드 및 업데이트 가능하도록 연동.

## 주의 사항
데이터의 용량이 매우 클 수 있으므로, 다운로드 후 즉시 `data/raw` 또는 `data/processed`에 배치하고 절대 git에 커밋되지 않도록 `.gitignore`를 확인하세요.
