# AI Hub (`aihubshell`) 외부 데이터 활용 매뉴얼

AI Hub(aihub.or.kr) 등 외부 채널에서 제공하는 개방형 데이터를 통해, DACON 대회에서 제공된 메인 데이터의 부족한 설명력을 보완(External Data)할 때 사용합니다.

## 🎯 사용 목적 (Why use this?)
- **은닉 패턴 발굴**: "모기의 활동량"은 대회에서 준 좌표 데이터뿐만 아니라, "그날의 습도와 강수량(기상청 데이터)"에 결정적인 영향을 받습니다. 외부 환경 요인을 조인(Merge)하여 모델 성능을 퀀텀 점프시킵니다.
- **Pre-training 코퍼스 확보**: 자연어 처리(NLP) 대회에서 주어진 대화 데이터가 고작 수천 개라면, AI Hub에 있는 수백만 개의 한국어 대화 말뭉치를 다운받아 언어 모델을 먼저 파인튜닝 시킵니다.

## 🚀 사용 방법 (How to use?)
웹 브라우저를 켜지 않고 백그라운드 스크립트(`aihubshell` 패키지)로 다운로드를 자동화하여 터미널 환경을 유지합니다.

```bash
# 설치 (최초 1회 AI Hub 계정 로그인 필요)
pip install aihubshell

# 필요한 데이터셋 고유 ID로 다운로드
aihubshell download -d [dataset_id] -o ./data/raw/external_data
```

## ⚠️ 실전 주의 사항 (매우 중요)
1. **대회 규정 필독**: 많은 Dacon/Kaggle 대회에서는 "외부 데이터 사용 전면 금지" 조항이 걸려있습니다. 외부 데이터를 다운로드하여 파이프라인에 조인하기 전에, 대회 규정(Rules) 탭에서 외부 데이터 사용이 허가되어 있는지 반드시 확인하세요. 미확인 시 실격 처리됩니다.
2. **Git 추적 금지**: 외부 데이터는 수백 GB에 달할 수 있습니다. 다운로드 경로를 반드시 `data/raw/` 하위로 지정하여, 본 템플릿의 `.gitignore` 정책에 따라 원격 저장소(Git)에 절대 업로드되지 않도록 감시하세요.
