# AI Hub CLI (`aihubshell`) 보조 데이터 확보 가이드

AI Hub(aihub.or.kr)는 수백 TB에 달하는 양질의 국내 개방형 데이터를 제공합니다. DACON 경진대회에서 모델의 성능 한계를 돌파하기 위해 "외부 보조 데이터(External Data)"를 합법적으로 수집 및 결합할 때 사용하는 필수 도구입니다.

---

## 1. CLI 환경 셋업
웹브라우저 클릭 없이 스크립트 기반으로 대용량 데이터를 백그라운드에서 안전하게 받기 위해 `aihubshell` 파이썬 패키지를 활용합니다.

```bash
# 패키지 설치
pip install aihubshell
```
최초 실행 시 AI Hub 웹사이트에서 회원가입한 이메일과 비밀번호를 터미널에 입력하여 토큰을 발급받아 캐싱합니다.

---

## 2. 보조 데이터(External Data) 활용 전략
대회의 메인 데이터셋만으로는 파악할 수 없는 숨겨진 패턴(Hidden Pattern)을 찾아낼 수 있습니다.

- **날씨/기상청 데이터 연계**: 교통량 예측, 모기 비행 궤적, 농작물 수확량 예측 등은 그날의 기온, 습도, 풍속, 강수량 등에 절대적인 영향을 받습니다. 일자별/지역별 기상 데이터를 조인(Merge)하여 강력한 파생 변수를 만듭니다.
- **지리 공간/GIS 정보**: 특정 좌표(위도/경도) 주변의 상권 정보, 도로망 정보, CCTV 밀집도를 결합하여 공간적 해상도를 높입니다.
- **한국어 Pre-training 코퍼스**: DACON의 NLP(자연어 처리) 대회 시 제공되는 데이터 수가 부족하다면, AI Hub의 방대한 한국어 대화 말뭉치를 다운받아 언어 모델을 사전에 파인튜닝(Domain Adaptive Pretraining) 한 뒤 본 대회 데이터에 적용합니다.

---

## 3. 다운로드 스크립트 자동화 및 보안 규율
데이터 다운로드 스크립트는 `scripts/download_aihub.sh` 등 별도의 파일로 격리하여 필요할 때만 실행하도록 구성합니다.

> **⚠️ 가장 중요한 보안 및 형상관리 규칙**
> 다운로드 받은 보조 데이터(CSV, JSON, ZIP 등)는 용량이 수십~수백 GB에 이를 수 있습니다. 
> 반드시 `data/raw/` 폴더 내부에 저장해야 하며, 베이스라인의 `.gitignore` 규칙에 의해 절대 **Git 저장소에 커밋(Push)되지 않도록 철저히 감시**해야 합니다. 
>
> *(또한 대회 규정에 외부 데이터 사용이 전면 허용되어 있는지 사전에 반드시 확인하세요.)*
