# AI Hub CLI (`aihubshell`) 가이드

AI Hub(aihub.or.kr)는 국내 양질의 개방형 데이터를 제공하는 핵심 채널입니다. Dacon 경진대회에서 모델의 강건성을 높이거나 부족한 변수를 채우기 위한 외부 보조 데이터(External Data) 수집용으로 활용합니다.

## 1. CLI 도구 셋업
AI Hub에서 직접 데이터를 다운로드하기 위해 `aihubshell` 파이썬 패키지를 활용합니다. 

```bash
# 전역 설치 또는 가상 환경 설치
pip install aihubshell
```
설치 후 AI Hub 홈페이지에서 발급받은 계정 이메일과 비밀번호를 초기 세팅해야 합니다.

## 2. 주 활용 목적
- **기상 데이터**: 모기 비행 궤적, 농작물 수확량, 교통 사고 등 기상 환경에 밀접한 영향을 받는 도메인에 적용.
- **지리 공간 및 환경 데이터**: 토지 정보, CCTV 영상 로그, 교통량 데이터 확보.
- **한국어 코퍼스**: 자연어 처리(NLP) 대회 시 사전 학습(Pre-training) 모델을 파인튜닝할 보조 코퍼스로 활용.

## 3. 자동화 다운로드 및 디렉토리 규율
다운로드 스크립트는 `scripts/` 아래에 별도 파일로 분리하고, 스크립트 실행을 통해 데이터를 내려받습니다.

**주의**: 다운로드 받은 보조 데이터는 용량이 매우 클 수 있으므로, 반드시 프로젝트의 `data/raw/` 폴더 하위에 두어 **`.gitignore`에 의해 커밋되지 않도록 철저히 격리**해야 합니다. 외부 데이터 활용 여부는 대회 규정(Rules)을 사전에 필히 확인해야 합니다.
