# AI Hub (`aihubshell`) 외부 데이터 활용 매뉴얼

DACON 메인 데이터의 부족한 설명력을 보완할 기상, 지리 등 양질의 국내 외부 보조 데이터(External Data)를 확보하기 위해 파이프라인에 도입한 CLI 도구입니다.

## 🎯 사용 목적 (Why use this?)
- **은닉 패턴 발굴**: 모기 활동량이나 교통량 예측 등은 주어진 데이터 외에 "그날의 강수량과 기온" 같은 외부 요인에 결정적인 영향을 받습니다. 이를 병합(Merge)하여 성능을 비약적으로 올립니다.
- **사전학습 코퍼스 수집**: 자연어 처리(NLP) 대회 시, 부족한 데이터셋을 보완하기 위해 AI Hub의 수백만 한국어 대화 말뭉치를 긁어와 먼저 파인튜닝(Pre-training)합니다.

## 🚀 사용 방법 (How to use?)

### 1. 인증 및 환경 변수 설정
최초 설치 후 AI Hub 계정에 대한 1회성 로그인이 필요합니다. (API 토큰과 달리 시스템 로그인 기반으로 세션이 유지됩니다.)
```bash
pip install aihubshell

# 최초 1회 실행 시 이메일/비밀번호 입력 창 활성화됨
aihubshell auth
```

### 2. 백그라운드 다운로드 자동화 스니펫
웹 브라우저를 켜지 않고 터미널에서 데이터를 받을 수 있습니다. 반복 작업이 필요하면 아래 스니펫을 별도 로컬 스크립트로 저장하되, 대용량 다운로드 결과는 반드시 `data/external/` 아래에 둡니다.

```bash
#!/bin/bash
# AI Hub에서 발급받은 특정 데이터셋 고유 ID로 다운로드
# 다운로드 폴더는 반드시 data/external (Git Ignore 대상)로 지정
aihubshell download -d "dataset_12345" -o "./data/external/aihub_weather"
```

## ⚠️ 실전 주의 사항
- **대회 규정 필독 (치명적 규정 위반 방지)**: DACON/Kaggle 대다수 대회는 "외부 데이터 사용 전면 금지" 조항이 걸려있습니다. 외부 데이터를 다운로드하기 전 반드시 대회 '규칙(Rules)' 탭에서 사용이 허가되어 있는지 확인하세요. 미확인 시 실격 처리됩니다.
- **Git 추적 절대 금지**: 외부 데이터는 수백 GB에 이를 수 있습니다. 다운로드 경로를 반드시 `data/external/` 하위로 지정하여, 본 템플릿의 `.gitignore` 정책에 의해 원격 저장소에 절대 업로드(Push)되지 않도록 통제하세요.
