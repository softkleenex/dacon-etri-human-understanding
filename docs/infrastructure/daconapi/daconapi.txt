👀 사용 예시 
⚠️ 주의

memo 내용만 선택사항이며, 그 외 모든 파라미터는 필수입니다.


일반 제출방식

파일 크기제한 : 100MB 이하

from dacon_submit_api import dacon_submit_api 

result = dacon_submit_api.post_submission_file(
'파일경로', 
'개인 Token', 
'대회ID', 
'팀이름', 
'메모 (선택사항)' )

print(result)


코드 제출방식

파일 크기제한 : 각 대회별 상세페이지 참고

from dacon_submit_api import dacon_submit_api 

result = dacon_submit_api.post_code_submission_file(
'파일경로', 
'개인 Token', 
'대회ID', 
'팀이름', 
'메모 (선택사항)' )

print(result)
