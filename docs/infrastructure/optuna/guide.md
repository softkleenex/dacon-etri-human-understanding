# Optuna 튜닝 가이드

모델의 성능을 극대화하기 위해 K-Fold 교차 검증과 연계된 베이지안 최적화 워크플로우입니다.

## 활용 목적
- LightGBM, XGBoost, CatBoost의 트리 깊이, 학습률, L1/L2 정규화 파라미터 최적화
- Neural ODE 및 Transformer 모델의 아키텍처 하이퍼파라미터 최적화

## 적용 패턴
- 랜덤 서치를 넘어서, 과거 실험 히스토리를 바탕으로 가장 효율적인 탐색 공간(Search Space)을 자동으로 찾아가는 방식으로 스크립트에 통합되어 있습니다.
- 백그라운드 파이프라인 진행 시 최적의 파라미터를 점진적으로 갱신합니다.
