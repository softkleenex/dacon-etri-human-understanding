# 데이터 전처리 및 MLOps 확장 라이브러리 가이드

기존 Pandas와 순수 PyTorch 코드를 발전시켜 파이프라인의 속도와 유지 보수성을 높이기 위한 도구들입니다.

## 적용된 도구 스택 [도입 완료]

### 1. Polars
- **역할**: 고속 데이터 전처리 및 피처 생성 (멀티스레딩 지원).
- **장점**: 수십~수백 개의 윈도우 통계량이나 시계열 파생 변수(FFT 등)를 생성할 때 기존 Pandas의 성능 병목을 획기적으로 해결합니다.

### 2. tsaug (Time Series Augmentation)
- **역할**: 궤적 시계열 데이터를 수학적으로 변형하여 데이터 증강.
- **적용 기법**: Time Warping, Magnitude Warping, Jittering 등을 궤적에 적용해 모델의 일반화 성능을 높입니다.

### 3. Geopandas
- **역할**: 3D 및 2D 공간 좌표 처리.
- **장점**: 다각형 펜스 설정, 곡률 및 궤적 교차 분석 등 수학적 연산보다 훨씬 직관적이고 풍부한 기하학적 피처 파생이 가능합니다.

### 4. DVC (Data Version Control)
- **역할**: 대용량 모델 가중치 및 데이터셋의 버전 관리.
- **활용**: Git으로 코드를 관리하고, DVC로 데이터 버전을 묶어 두어 실험 재현성을 완벽히 보장합니다.

### 5. PyTorch Lightning
- **역할**: PyTorch 학습 루프의 보일러플레이트 제거.
- **장점**: Mixed Precision(16-bit) 적용, Multi-GPU 스케일링, Early Stopping 콜백, W&B 연동이 단 몇 줄의 코드로 요약됩니다.
