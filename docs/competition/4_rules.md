# 🚨 대회 규칙 및 제약 사항 (Rules & Constraints)

## 1. 외부 데이터 규정 (External Data)
- 외부 데이터 사용 가능
- 공식 공개 사전 학습 모델 사용 가능: 가중치 파일이 공식적으로 공개되어 있고, 다음 중 하나에 해당하는 경우 사용이 가능:
  - 오픈소스 라이선스로 공개되어 있으며, 상업적 이용을 포함한 자유로운 사용이 가능한 경우
  - 상업적 이용은 불가능하나, 연구 목적으로는 사용이 명시적으로 허용된 경우 (예: non-commercial 또는 research-only 라이선스)

## 2. 참가 및 팀 구성 
- 참가 신청일(2026.04.13) 기준 만 19세 이상 (대학생의 경우 나이제한 없음)
- 개인 또는 팀 (최대 4명)
- 동일인 중복 참여 불가
- 지도교수는 논문 저자 명시하되 팀에서는 제외. 참가팀 전원 논문 저자로 포함 필수.

## 3. 코드 공유 및 프라이빗 룰 (Code Sharing)
- 대회 기간 내 팀 외의 모든 인사이트 및 코드 공유는 데이콘 플랫폼 내에서 공개적으로만 이루어져야 하며 비공식 공유는 Private Sharing으로 간주됨.
- 데이콘 답변은 토크 페이지나 이메일 문의.

## 4. 논문 제출 방법
- ICTC 2026 EDAS 시스템을 통해 'ICTC Workshop on ETRI Human Understanding AI Paper Challenge (IWETRIAI) 부문'에 투고
- 타 학술지 발표되지 않은 논문이어야 함.
- 형식: Standard IEEE conference templates, 4-page full paper 양식.

## 5. 코드 및 모델설명서 제출 규칙
- 논문 채택된 팀은 dacon@dacon.io로 팀명 포함하여 제출
- 코드에 ‘/data’ 데이터 입/출력 경로 포함
- 확장자: .R, .rmd, .py, .ipynb
- 코드와 주석 인코딩: UTF-8
- 개발 환경(OS) 및 라이브러리 버전 기재
- 사전 학습 모델 출처 및 다운로드 링크 기재
- Private 리더보드 스코어 복원 가능해야 함.
