# 🚨 대회 규칙 및 제약 사항 (Rules & Constraints)

대회에서 실격(Disqualification)당하지 않기 위해 반드시 지켜야 하는 룰을 명시합니다. 에이전트(Gemini CLI)가 이 문서를 읽고 절대 넘어서는 안 될 선(Guardrails)을 파악합니다.

## 1. 외부 데이터 규정 (External Data)
- [ ] 외부 데이터 사용 전면 금지 (Strictly Prohibited)
- [ ] 주최 측이 제공/허가한 사전 학습 모델(Pre-trained Model)만 허용
- [ ] 대회 게시판에 공유되고 승인받은 외부 데이터만 사용 가능
- (해당하는 곳에 체크하고 구체적인 허용 범위를 적어두세요.)

## 2. 코드 공유 및 프라이빗 룰 (Code Sharing)
- 팀원 외 다른 참가자와 사적으로 코드를 공유하는 것은 금지됩니다.
- (기타 금지 사항 메모)

## 3. 컴퓨팅 자원 및 추론 시간 제한 (Resource Limits)
- (코드 제출형 대회의 경우만 작성)
- 예: "CPU 4코어, RAM 16GB 이하의 환경에서 추론 시간이 파일당 10초 이내에 완료되어야 함."

> **💡 에이전트 금지 사항 (Agent Guardrails)**
> 에이전트는 외부 데이터를 결합(`src/features.py` 병합)하거나 허가받지 않은 대용량 LLM 가중치를 Hugging Face에서 다운받기 전, **반드시 이 문서를 참조하여 해당 행위가 룰 위반인지 검토해야 합니다.** 위반일 경우 작업을 즉각 취소하세요.
