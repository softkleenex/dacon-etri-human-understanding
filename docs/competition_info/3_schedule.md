# 🗓 대회 일정 및 중요 기한 (Schedule & Deadlines)

대회 기간 중 잊지 말아야 할 마일스톤(Milestone)을 기록합니다.

## ⏳ 핵심 일정 (Timeline)
- **참가 접수 마감**: YYYY-MM-DD HH:MM
- **팀 병합 마감**: YYYY-MM-DD HH:MM
- **외부 데이터 사용 신청 마감**: YYYY-MM-DD HH:MM
- **코드 및 결과물 제출 마감**: YYYY-MM-DD HH:MM

## ⏰ 일일 제출 규칙 (Daily Quota)
- **하루 최대 제출 가능 횟수**: N회 (예: 3회)
- **횟수 리셋 시간**: 매일 오전 / 자정 HH:MM (예: 매일 오전 10시 리셋)

> **💡 에이전트 작업 지침**
> 에이전트는 자동 제출 스크립트를 가동하기 전에 반드시 오늘 사용 가능한 제출 횟수(Quota)가 남아있는지 확인하고, K-Fold OOF 점수가 기존 최고 기록을 넘었을 때만 1일 N회를 초과하지 않도록 제출을 통제해야 합니다.
