## 미결 항목 — 저자 등록

### 조건

- ICTC 규정: 채택 논문은 저자 최소 1인이 **Regular rate** 로 등록해야 하며
  학생 요금으로는 저자 요건을 충족하지 못한다. 1등록 = 1논문.
- 금액: 회원 $650 / 비회원 $720 (조기 기준). 약 90~100만원.
- 마감: 2026-09-17.

### 등록하지 않을 경우

**논문**
- proceedings 미게재, IEEE Xplore 미등재
- 채택 상태는 남지만 실적으로 쓸 수 없음
- 포스터 세션 참석 불가

**DACON 대회**
- DACON 공식 답변(2026-04-23, DACON.PSH):
  > 본 대회는 리더보드 제출, 논문 등록, 코드 및 모델 설명서 제출을 모두
  > 완료한 팀에 한하여 최종 평가가 진행됩니다. 따라서 논문 제출 및 채택만으로
  > 종합 평가 대상이 되는 것은 아니며, **저자 등록까지 완료된 팀에 한하여
  > 종합평가가 진행됩니다.**
- 즉 저자 등록 미완료 시 **종합평가 대상에서 제외**되며 수상 가능성은 없다.
- 포스터 세션·시상식 불참 시에도 수상 자격이 제외될 수 있다.

**위약금이나 별도 불이익은 없다.** 등록하지 않으면 아무것도 남지 않을 뿐이다.

### 판단에 필요한 미확인 정보

1. **DACON이 기한 초과 코드 제출을 접수했는가** — 가장 중요.
   접수되지 않았다면 저자 등록을 해도 종합평가 대상이 아니므로,
   등록비는 오직 논문 게재만 사는 것이 된다.
2. ICTC 저자 등록 마감 연장 또는 late registration 가능 여부.
   가능하다면 DACON 수상 발표(09-22) 이후로 결정을 미룰 수 있다.
3. 등록비 지원 가능 경로.
   - DACON/ETRI 측 지원 제도 유무 — 대회 안내에 언급 없음
   - 경북대 논문 게재료 지원 제도는 **학술지(SCIE/SCOPUS/KCI) 게재료** 대상이라
     IEEE 학회 proceedings 등록비에는 적용이 어려울 가능성이 높음.
     별도로 존재할 수 있는 **국제학술대회 발표·참가비 지원** 제도를 확인해야 함.
   - 실비 정산 방식이면 마감 전 선결제가 필요하다.

### 참고 — 수상 가능성에 대한 정직한 평가

- ID342 공개 리더보드 순위 `220` (2026-06-23 제출 시점)
- 총 상금 530만원, 1~5위 배분
- 다만 종합평가 모수는 전체 참가자가 아니라 "논문 채택 + 코드 제출 + 저자 등록"을
  모두 마친 팀으로, 220위라는 숫자보다 훨씬 작은 풀이다.
- 평가 요소는 재현성 검증 통과를 전제로 참신성·기술적 완성도·기여도이며
  리더보드 순위만으로 결정되지 않는다.
- 리더보드 성적이 약하고 코드 제출이 늦은 것은 사실이므로 기대치를 높게 잡을
  근거는 없다. 다만 "가능성 없음"으로 단정할 근거도 없다.

## 알려진 기술적 이슈 (참고)

DACON 제출 코드 패키지에 다음 제약을 명시해 두었다.

- 최종 제출 CSV는 `code/reproduce_submission.py` 로 **SHA-256 일치**하게 재현된다
  (`02f622e1e9c6825727a5d1cdc482fd505f6f7086c92def5fbb43c4198e13b394`).
- 50단계 전체 계보 재실행(`code/replay_lineage.py`)은 오류 없이 완주하지만,
  5번째 단계(ID108)부터 수치 편차가 누적되어 최종 ID342 기준 log loss
  `+0.000845` 차이가 발생한다.
- 원인은 2026년 6월 원 실험 시점의 scikit-learn/numpy 버전을 기록해 두지
  않은 것이며, 무작위성이나 데이터 변경이 아님을 확인했다.
  (시드 고정 확인, 스레드 수 고정 확인, 데이터 파일 변경 이력 없음,
  원본 부모 행렬 입력 시 각 단계는 bit-exact 재현됨)
- 실험 환경 버전을 고정·기록하지 않은 것은 실질적 결함이며, 제출 문서
  `docs/REPRODUCIBILITY.md` 4절에 측정치와 함께 그대로 보고했다.

## 최종 결과 (2026-10-28 기록)

위 문서는 2026-09-16 "결정 대기" 상태에서 멈춰 있었다. 이후 경과와 최종 결론을 기록한다.

### 1. 데이콘 회신 (2026-09-17)

9/15 발송한 기한 후 제출에 대해 회신을 받았다. 요지는 세 가지다.

- 제출 자료는 확인됐으나, **기한 이후 접수 건은 주최 측과 논의 중**이며 결정되면 별도 안내.
- 검증 통과 여부와 별개로 **게재 요건은 저자 등록 완료 + 포스터 세션 참석**.
- **재현성 검증 미충족**: 재현성은 원본 데이터 파일을 입력으로 전처리 → 특징 생성 → 학습 →
  추론 → 최종 `submission.csv` 까지 생성 가능해야 한다. 제출 코드는 저장된 OOF·test 예측과
  lineage seed로 최종 파일을 복원하고 있어 원본 데이터만으로 전체 과정을 재현할 수 없다.
  기존 cache·lineage_seed·저장된 예측을 입력으로 재사용하지 않도록 보완해
  **2026-09-18 13:00 까지 재제출** 요청.

### 2. 재제출하지 않음

9/18 13:00 까지 보완본을 보내지 않았다. 요구된 보완은 패키징 수정이 아니라
50단계 계보를 원본 데이터부터 버전 고정해 다시 세우는 파이프라인 재설계이며,
하루 안에 가능한 작업이 아니었다.

지적 자체는 정확하다. `code/reproduce_submission.py` 는 저장된 예측 행렬을 재조립해
SHA-256 일치를 보장하지만 원본 데이터에서 출발하지 않는다. 원본에서 출발하는
`code/replay_lineage.py` 는 완주하되 버전 미고정으로 최종 log loss `+0.000845` 편차가 있다.
즉 파이프라인에 "원본 데이터 → 최종 CSV" 단일 경로가 애초에 존재하지 않았다.

### 3. 저자 등록하지 않음

ICTC 저자 등록·결제를 하지 않았다. 따라서 포스터 세션에도 불참했다.

문서 작성 시점에 놓쳤던 사실 두 가지를 뒤늦게 확인했다 (출처: https://ictc.org/ 공식 공지).

- **저자 등록 마감은 2026-09-17 이 아니라 2026-09-21 로 연장**되어 있었다.
  camera-ready 마감도 동일하게 9/17 → 9/21 연장. 위 본문의 "마감 내일" 전제는 틀렸다.
- **발표 저자(학생·신진연구자) 대상 travel grant 최대 $500** 제도가 있었다.
  단 신청 마감이 2026-09-10 으로, 등록비 지원 경로를 찾기 시작한 시점에 이미 지났다.
