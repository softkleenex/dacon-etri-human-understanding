# 📥 인박스 (User-Agent Inbox & Dropzone)

이 폴더(`_inbox/`)는 사용자(당신)와 AI 에이전트(Gemini CLI) 간의 **소통 창구이자 임시 파일 보관소(Dropzone)**입니다. 

## 🎯 사용 목적 (Why use this?)
대회를 진행하다 보면 텍스트만으로 에이전트에게 상황을 설명하기 어려운 순간들이 있습니다.
- **이미지 제공**: 대회 홈페이지의 복잡한 평가 산식 수식 이미지, 에러가 발생한 화면의 스크린샷, 데이터 분포 그래프 이미지 등을 이 폴더에 넣고 에이전트에게 분석을 요청하세요.
- **PDF 및 외부 문서**: 대회 주최 측에서 제공한 가이드라인 PDF 파일이나 규정 문서 등을 임시로 넣어두고 요약/분석을 지시할 수 있습니다.
- **임시 메모**: 에이전트에게 길게 설명해야 하는 구조도나 프롬프트 지시사항을 `instruction.txt` 같은 파일로 이곳에 적어두면 에이전트가 읽고 작업을 수행합니다.

## 🚀 사용 방법 (How to use?)
1. 사용자가 대회 규칙 스크린샷(`rules.png`)을 이 폴더에 끌어다 놓습니다.
2. 터미널에서 에이전트에게 지시합니다.
   > *"_inbox/rules.png 이미지를 읽고, 이번 대회에서 우리가 쓸 수 없는 외부 데이터 제약 조건이 뭔지 파악해서 docs/competition_info/4_rules.md 에 업데이트 해줘."*
3. 에이전트가 이미지를 분석하고 작업을 완료합니다.
4. **작업이 끝난 임시 파일은 사용자가 비워주시면(삭제) 됩니다.**

## ⚠️ 형상 관리 주의 사항 (.gitignore)
이 폴더는 철저히 **임시 소통 공간**이므로, 용량 낭비를 막기 위해 이 폴더에 들어오는 모든 이미지(`*.png`, `*.jpg`), 문서(`*.pdf`) 파일들은 Git 저장소에 커밋되지 않도록 `.gitignore`에 차단 설정이 되어 있습니다. (단, 이 `README.md` 파일 자체는 유지됩니다.)
