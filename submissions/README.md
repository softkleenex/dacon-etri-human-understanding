# Submissions Directory

This directory is for leaderboard-facing prediction artifacts and their immediate metadata only.

Keep here:
- `submission_log.csv`: canonical submission history, normalized by `make normalize-submissions`.
- `submission_*.csv`: DACON-ready prediction files with immutable, descriptive names.
- `oof_*.csv`: out-of-fold predictions used for stacking and validation.
- `user_embeddings_*.csv`: compact embedding features used by downstream stacking.
- `*_meta.json`: lightweight metadata for a matching submission file.

Do not keep here:
- raw data, copied source trees, training checkpoints, Lightning logs, Optuna databases, or Kaggle error bundles.
- Put those under ignored `artifacts/`, `models/`, `data/`, or `reports/` as appropriate.

Before ensembling or submitting:

```bash
make normalize-submissions
make ensemble
make audit
```

## Naming convention

Avoid generic names such as `submission.csv` for preserved artifacts. Use descriptive, immutable names:

```text
submission_id_<log-id>_<short-model>_cv<score>_<status>.csv
```

Examples:
- `submission_id_089_v32_stacking_cv0.600075_unscored.csv`
- `submission_id_076_v31_patch_cv0.599611_public0.624152.csv`

`submission_ensemble_latest.csv` may be regenerated by `make ensemble`; do not treat it as a permanent historical artifact unless copied to an immutable name.
